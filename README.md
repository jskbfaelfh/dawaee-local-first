# نظام دوائي (Dawaee SaaS)
## نظام إدارة الصيدليات (POS) + شبكة البحث المركزي عن الأدوية في العراق

---

## 🌟 نظرة عامة على النظام

نظام سحابي (SaaS) متكامل ومخصص لسوق الصيدليات في العراق يجمع بين:
1. **نقطة بيع سريعة (POS)** تدعم البيع بالعلبة والشريط، والخصم التلقائي بنظام FEFO، والسماح بالبيع بالسالب.
2. **إدارة المخزون والوجبات (Batches)** مع جدول إدخال فواتير المذاخر الجماعي وتنبيهات الصلاحية والنواقص.
3. **معمارية عزل متعددة المستأجرين (Schema-per-tenant)** توفر أماناً وعزلاً تاماً لبيانات كل صيدلية داخل PostgreSQL.
4. **شبكة بحث مركزية لحظية (Public Drug Network)** تتيح للمرضى البحث عن الدواء ومعرفة الصيدلية المتوفر فيها، السعر بالدينار العراقي، الموقع على خرائط جوجل، ورقم الهاتف.
5. **لوحة إدارة عليا (Super Admin)** لتوليد الصيدليات آلياً، إدارة التراخيص والاشتراكات، وقفل التعديل بوضع القراءة فقط (Read-Only) عند انتهاء الاشتراك.

## 🏗️ الهيكل التقني للمشروع

```text
دوائي/
├── backend/                  # تطبيق NestJS + Prisma ORM + PostgreSQL
│   ├── prisma/
│   │   └── schema.prisma     # مخطط قاعدة البيانات (Master & Tenant schemas)
│   ├── src/
│   │   ├── common/           # Tenant Context (AsyncLocalStorage), Guards, Interceptors
│   │   ├── database/         # PrismaService مع dynamic search_path
│   │   └── modules/
│   │       ├── auth/         # تسجيل الدخول وتوليد JWT
│   │       ├── admin/        # إدارة المالك والتوليد الآلي للصيدليات (Provisioning)
│   │       ├── medicines/    # الكتالوج المرجعي العام للأدوية
│   │       ├── inventory/    # إدخال الوجبات، المخزون، وتنبيهات الصلاحية
│   │       ├── pos/          # محرك المبيعات، الفواتير، والمرتجعات السريعة
│   │       ├── search/       # المزامنة الفورية ومحرك البحث العام للمرضى
│   │       └── reports/      # تقارير الأرباح والمبيعات وتقييم المخزون
│
└── frontend/                 # تطبيق React + Vite + Tailwind CSS (RTL بالعربية)
    ├── src/
    │   ├── api/client.ts     # عميل الـ API والاتصال بالـ Backend
    │   ├── views/
    │   │   ├── PosView.tsx               # شاشة الكاشير السريعة ونقطة البيع
    │   │   ├── BulkStockEntryView.tsx    # شاشة إدخال وجبات فواتير المذاخر
    │   │   ├── InventoryView.tsx         # شاشة المخزون وتعديل الأسعار والوجبات
    │   │   ├── ReportsView.tsx           # شاشة التقارير المالية والأرباح
    │   │   ├── PublicSearchView.tsx      # صفحة البحث الشبكي العام للمرضى
    │   │   ├── SuperAdminView.tsx        # لوحة المالك وتوليد الصيدليات
    │   │   └── LoginView.tsx             # شاشة تسجيل الدخول
    │   └── App.tsx                       # شريط التنقل الرئيسي والتحكم بالشاشات
```

## 🚀 طريقة التشغيل السريع (Quick Start)

### 1. تشغيل الـ Backend:
```bash
cd backend
npm run start:dev
```
*سيعمل السيرفر على: `http://localhost:4000/api`*

### 2. تشغيل الـ Frontend:
```bash
cd frontend
npm run dev
```
*ستعمل الواجهة على: `http://localhost:3000`*

## 🔑 إعداد حساب مدير النظام (Super Admin)

يتم ضبط بيانات حساب مدير النظام العام عبر ملف البيئة `.env` في مسار `backend/.env`:
* `ADMIN_USERNAME`: اسم مستخدم المدير العام (مثلاً: `admin_user`).
* `ADMIN_PASSWORD`: كلمة مرور قوية ومعقدة (يجب ألا تقل عن 10 خانات).

> ⚠️ **تنبيه أمني:** لا تقم برفع ملف `.env` إطلاقاً إلى مستودعات Git أو GitHub العامة. تأكد من تعيين كلمات مرور عشوائية قوية على بيئات الاستضافة السحابية (Railway / Render / Vercel).
